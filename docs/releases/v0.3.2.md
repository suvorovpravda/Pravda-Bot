# Pravda-Bot v0.3.2 — correction de la fenêtre Windows

**Préversion corrective** remplaçant v0.3.1 pour les nouveaux téléchargements.

## Correctif principal

Corrige le blocage de la fenêtre Windows sur `{"error":"request origin not allowed"}` après le lancement de `pravda-app.exe`.

La cause était la protection HTTP `Sec-Fetch-Site`, qui rejetait la **première navigation de WebView2 depuis Tauri** lorsque Chromium la classait `cross-site`. Le serveur local lui-même démarrait correctement, mais l'interface n'affichait que cette réponse JSON.

Désormais, la navigation est autorisée **uniquement** pour les documents publics `GET /` et `GET /login` avec des en-têtes `Sec-Fetch-Mode: navigate` et `Sec-Fetch-Dest: document`, sur l'hôte de boucle locale attendu, sans en-tête Origin. Les API, requêtes POST, WebSocket, origines externes et accès non conformes restent protégés.

## Vérifications ajoutées

- Tests Rust positifs de navigation initiale WebView2, et tests négatifs (API, WebSocket, POST, Origin externe, mauvais mode/destination).
- Test Windows de démarrage Tauri comprenant une requête qui reproduit les en-têtes WebView2.
- Validation Rust Ubuntu/Windows, MSRV et CodeQL avant publication.
- Compilation de l'exécutable Windows x64 en mode release et contrôle de démarrage.

## Installation

1. Télécharger `Pravda-Bot-v0.3.2-Windows-x64.zip` dans les fichiers de cette release.
2. Extraire l'archive dans un nouveau dossier.
3. Lancer `pravda-app.exe`.
4. Définir le mot de passe local à la première utilisation.

Le programme utilise par défaut `127.0.0.1:8080` et peut nécessiter Microsoft Edge WebView2 Runtime. Si une ancienne instance Pravda-Bot tourne déjà, la fermer avant de lancer la nouvelle version.

Ne pas écraser ses données `pravda.db` ni le fichier d'authentification `pravda_auth.json` lors de la mise à jour. Il s'agit d'une **application portable**, pas d'un installateur MSI. Pas d'ordres de trading réels.
