# Pravda-Bot v0.3.1 — mise à jour corrective

**Préversion (prerelease)** · Mise à jour de `v0.3.0`

Cette version remplace `v0.3.0` pour les nouvelles installations : la release `v0.3.0` est immuable, son tag d'origine est conservé. Le code correspondant à cette version est basé sur les modifications validées dans `main`.

## Nouveautés et correctifs

- **Authentification locale** du tableau de bord, des routes API et du flux WebSocket : mot de passe défini à la première utilisation, empreinte PBKDF2 salée, sessions limitées dans le temps, cookies HttpOnly/SameSite et déconnexion.
- **Démarrage du client Windows Tauri fiabilisé** : l'application attend la disponibilité du serveur local, refuse les ports occupés et les services inattendus, et n'ouvre qu'une seule fenêtre.
- **Sécurité du stockage du mot de passe** : création de fichier sans remplacement d'un enregistrement existant, exclusion des fichiers d'authentification et temporaires du dépôt.
- **Tests de sécurité améliorés** : identifiants de test générés aléatoirement et suppression des messages de test incorporant des réponses HTTP non fiables.
- **Mise à jour des fichiers Cargo.lock**, corrections rustfmt, tests de démarrage et vérifications Windows/Linux/MSRV.
- **Synchronisation locale Windows sans écrasement** : script `tools/sync-and-run-windows.ps1` disponible dans les sources.

## Installation (Windows x64)

Télécharger l'archive `Pravda-Bot-v0.3.1-Windows-x64.zip` depuis les fichiers de cette release (si disponible), puis l'extraire. Exécuter `pravda-app.exe` et définir un mot de passe local lors du premier lancement. Une installation compatible de **Microsoft Edge WebView2 Runtime** peut être nécessaire pour la fenêtre Tauri. Le programme démarre son propre serveur sur `127.0.0.1:8080` par défaut (configurable avec `DASHBOARD_PORT`).

L'archive contient le binaire Windows et sa documentation ; ce n'est pas un installateur MSI, et elle ne remplace pas automatiquement un dossier local existant. Conserver les fichiers de données `pravda.db` et `pravda_auth.json` lors d'une mise à niveau.

## Limites

Pravda-Bot est un **observatoire de marchés et simulateur papier**. Aucun ordre réel n'est transmis, aucun compte d'exchange n'est contrôlé. Le client Tauri et certaines interfaces restent en migration ; des fonctions historiques Python (actualités, Forex, énergie, AIS) ne sont pas intégralement portées. Les protections locales ne remplacent pas la sécurité du poste hôte.
