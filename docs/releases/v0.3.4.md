# Pravda-Bot v0.3.4 — lisibilité et stabilité du tableau de bord Windows

**Préversion corrective Windows x64** publiée après les validations Rust, JavaScript et CodeQL.

## Correctifs du terminal

- **Cotations USDT visibles sans dépendance au Forex** : mode graphique USDT sélectionné par défaut, et prix natifs affichés à côté des champs EUR/CHF. Les conversions EUR/CHF demeurent marquées indisponibles tant qu'aucun taux de change vérifié n'est disponible. Aucun taux fictif n'est calculé.
- **Historique moins coûteux** : les cotations de marché peuvent être rafraîchies chaque seconde sans relire systématiquement jusqu'à 10 001 lignes SQLite. L'historique est rafraîchi séparément toutes les 30 secondes et lors des changements de sélection.
- **Alertes de simulation affichées sans erreur** : les événements papier utilisent les vrais champs JSON du serveur Rust (`symbol`, `message`, `timestamp`). Pas de faux boutons de suppression ni de champs `undefined`.
- **Création d'alertes de seuil correctement signalée indisponible** : le formulaire est désactivé tant que l'API Rust ne gère pas leur enregistrement. Messages en français, russe et anglais.
- **Horodatage corrigé** : utilisation du champ `timestamp` réellement envoyé par le serveur.
- **WebSocket plus robuste** : reconnexion progressive (jusqu'à 30 s) sans rechargement automatique continu de la fenêtre ; retour à l'écran de connexion à expiration de la session HTTP.

## Vérification

Le workflow Rust teste la syntaxe de l'interface et des cas d'exécution JavaScript sous Node.js sur Ubuntu et Windows (cotations sans Forex, alertes de simulation, cadences, absence de boucles de rechargement). Les contrôles Rust Linux/Windows, la compatibilité MSRV, l'analyse CodeQL, la compilation et le démarrage Windows Tauri doivent également réussir.

## Installation

Télécharger `Pravda-Bot-v0.3.4-Windows-x64.zip` dans les **Assets** de la release, extraire puis lancer `pravda-app.exe`. Conserver les données existantes dans `%LOCALAPPDATA%\Pravda-Bot` et fermer l'ancienne instance avant le lancement. Ne pas utiliser le bouton GitHub « Code / Download ZIP » : celui-ci fournit uniquement les sources.

Cette version reste un **observatoire et simulateur papier**, sans ordres réels. Certaines sections héritées de l'ancien dashboard Python (Forex, ENTSOG, AIS, actualités et seuils personnalisés) ne sont pas encore intégralement migrées vers Rust. Les tests CI ne remplacent pas la validation de l'interface sur un PC utilisateur.
